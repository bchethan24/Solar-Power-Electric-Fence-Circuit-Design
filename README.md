# Solar Powered Electric Fence

An off-grid agricultural protection system designed to deliver controlled, safe electric pulses using renewable energy.

## 🛠 Technical Specifications
- **Oscillator:** CD4047 IC (Astable Mode)
- **Switching:** Dual IRF3205 MOSFETs
- **Regulation:** LM317L Adjustable Regulator
- **Power:** 12V 7Ah Lead-Acid Battery + Solar Charging
